# 책상 위 — 작은 직업상담실

기존 앱의 장면·이론·학습 시간·상담 기록·시험 안내를 보존한 로컬 개선본입니다.

## 사용

의뢰서로 장면을 읽고, 상담 메모에서 한 문장을 건네세요. 흥미·적성·가치 관련 질문에 준비된 내담자 반응과 개념 연결이 표시됩니다. 이론 서랍에서 기존 이론을 읽고 상담으로 돌아올 수 있습니다. 시간 선택, 조명, 찻잔, 기록함도 사용할 수 있습니다.

현재 상담은 키워드와 준비된 대사에 기반하며 AI 모델을 호출하지 않습니다. 외부 API 키나 비용 없이 동작합니다. 이해되지 않은 입력은 구체적인 질문을 안내하며 정답이나 점수를 판정하지 않습니다.

5개 과목에 31개의 핵심 이론 카드를 추가했습니다. 공식·연구기관 공개자료 21개를 참고해 설명을 새로 썼으며, 카드마다 출처와 2026-10-14 확인일이 있습니다. 과목 선택·키워드 검색·예시 질문 가져오기를 지원합니다. 작성 중 메모가 있으면 이어 붙일지 선택할 수 있습니다. 상담 대화는 현재 민정 씨 한 건입니다.

법규는 2026-10-08 시행 근로기준법을 기준으로 대조했고, 현재 산업분류·직업분류와 2026년 조사 정의를 반영했습니다. 과거 기출의 문항과 정답, 과거 월별 통계 수치, 검사 문항, 유료 교재 본문과 기관 그림은 포함하지 않습니다. 설명은 새 요약, 질문과 장면 예시는 새 창작입니다. 자료는 자동 갱신되지 않습니다. 각 출처의 사용 방식은 앱 자료집에서 확인할 수 있습니다. 전체 출제기준을 모두 다루는 완성 교재라는 뜻은 아닙니다.

자료: `js/library-data.js`, 화면 연결: `js/library.js`. 원본 시험 일정 중 확인된 2026년 일정은 유지했으며, 직접 확인하지 못한 세부 시험 방식은 현재 큐넷 출제기준 링크로 안내합니다.

기존 저장 키 `desk-lamp-v1`을 유지합니다. 추가 대화와 발견한 조각은 `desk-game-conversation-v1`, 작성 중인 문장은 `desk-game-draft-v1`, 조명은 `desk-game-lamp`에 브라우저별로 저장합니다. 다른 주소 또는 브라우저에는 자동으로 동기화되지 않습니다.

## 실행

```sh
python3 -m http.server 8765
```

`http://localhost:8765`로 접속하세요. 원본 CSS 컴포넌트의 MIT 라이선스 표기를 유지했습니다.
